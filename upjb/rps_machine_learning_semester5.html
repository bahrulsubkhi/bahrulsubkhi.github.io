Batas Cakupan vs Kecerdasan Buatan (Sem 4) — wajib dipegang dosen pengampu

Kecerdasan Buatan (Sem 4) memakai library ML sebagai black box untuk implementasi cepat. Machine Learning (MK ini) mempelajari MENGAPA algoritmanya bekerja: gradient descent dan backpropagation harus diajarkan sebagai custom training loop (implementasi manual dengan NumPy, dibandingkan dengan versi library/PyTorch) — bukan sekadar memanggil model.fit().
