Clustering
Menemukan struktur tersembunyi dalam data tanpa label — Unsupervised Learning
Definisi

Apa itu Clustering?

Clustering adalah teknik unsupervised learning yang mengelompokkan data berdasarkan kemiripan (similarity) tanpa label kelas yang sudah ditentukan. Berbeda dengan klasifikasi, clustering menemukan pola atau struktur tersembunyi secara otomatis.

Tujuan: Maximize(intra-cluster similarity) AND Minimize(inter-cluster similarity)

Clustering vs Klasifikasi

K-Means Clustering
Algoritma partisi berbasis centroid — simpel, cepat, dan efektif
Algoritma Partisi

Definisi & Objektif

K-Means mempartisi n titik data ke dalam K cluster dengan meminimalkan Within-Cluster Sum of Squares (WCSS).

J = Σᵢ₌₁ᴷ Σ_{x∈Cᵢ} ||x - μᵢ||²

μᵢ = centroid cluster ke-i, Cᵢ = himpunan titik dalam cluster i

Kompleksitas: O(n · k · i · d)

n=data, k=cluster, i=iterasi, d=dimensi

Langkah Algoritma

1

Inisialisasi: Pilih K centroid awal (random atau K-Means++)

2

Assignment: Setiap titik → cluster centroid terdekat berdasarkan Euclidean distance

3

Update: Hitung ulang centroid = rata-rata titik dalam cluster

4

Konvergen? Jika centroid tidak bergerak → selesai. Jika tidak → ke langkah 2

Kelebihan & Kekurangan

Simple & intuitif Scalable O(nki) Mudah diinterpretasi Efisien data besar Harus tentukan K Sensitif outlier Hanya cluster bulat Bergantung inisialisasi Fitur perlu normalisasi

DBSCAN
Density-Based Spatial Clustering of Applications with Noise
Density-based

Konsep Dasar

DBSCAN menemukan cluster berdasarkan kepadatan lokal data. Tidak perlu menentukan K, mampu mendeteksi cluster berbentuk arbitrer, dan robust terhadap noise/outlier.

N_ε(p) = {q ∈ D | dist(p,q) ≤ ε}

N_ε(p) = neighborhood titik p dalam radius ε

Parameter & Tipe Titik

ε (epsilon) — Radius Neighborhood

Dua titik dianggap "tetangga" jika jarak mereka ≤ ε

MinPts — Minimum Titik

Jumlah minimum titik dalam N_ε(p) agar p menjadi core point

Core point: |N_ε(p)| ≥ MinPts
Border point: dalam N_ε core point, bukan core
Noise/Outlier: tidak terjangkau dari mana pun

Algoritma DBSCAN

1

Untuk setiap titik p yang belum dikunjungi, hitung N_ε(p)

2

Jika |N_ε(p)| < MinPts → tandai sebagai noise

3

Jika |N_ε(p)| ≥ MinPts → buat cluster baru, expand dari p

4

Expand: tambahkan semua density-reachable titik ke cluster

5

Ulangi untuk semua titik yang belum dikunjungi

Kapan Gunakan DBSCAN?

  • Data mengandung outlier/noise signifikan
  • Jumlah cluster tidak diketahui sebelumnya
  • Cluster berbentuk non-konveks (ring, spiral, dsb.)
  • Data spasial (koordinat GPS, peta)
  • Deteksi anomali pada sensor data
⚠️ DBSCAN kurang efektif jika densitas cluster sangat bervariasi (gunakan HDBSCAN untuk kasus tersebut)

Linkage Methods

Single Linkage (min)

d(A,B) = min{dist(a,b) | a∈A, b∈B} — cenderung membentuk cluster panjang/chain

Complete Linkage (max)

d(A,B) = max{dist(a,b)} — menghasilkan cluster yang lebih kompak

Average Linkage (UPGMA)

d(A,B) = avg semua pasang — keseimbangan antara single & complete

Ward Linkage ⭐

Minimasi peningkatan total within-cluster variance — paling populer

Gaussian Mixture Models (GMM)
Model probabilistik dengan Expectation-Maximization — soft assignment
Model-based

Definisi

GMM mengasumsikan data berasal dari campuran K distribusi Gaussian. Setiap titik memiliki probabilitas keanggotaan terhadap setiap cluster (soft assignment).

p(x) = Σₖ₌₁ᴷ πₖ · N(x | μₖ, Σₖ)

• πₖ = mixing coefficient (prior), Σπₖ = 1

• μₖ = mean vektor Gaussian ke-k

• Σₖ = covariance matrix Gaussian ke-k

Algoritma EM (Expectation-Maximization)

E
Expectation Step

Hitung responsibility: r(nk) = πₖN(xₙ|μₖ,Σₖ) / Σⱼπⱼ N(xₙ|μⱼ,Σⱼ)

M
Maximization Step

Update μₖ, Σₖ, πₖ menggunakan responsibility yang dihitung di E-step

∞

Ulangi E↔M sampai log-likelihood konvergen

🧭 Decision Guide — Pilih Algoritma yang Tepat

📏 Metrik Evaluasi Clustering

Internal (tanpa ground truth)

Silhouette Score [-1, 1]

Seberapa mirip titik dengan clusternya vs cluster tetangga. Semakin tinggi semakin baik.

s(i) = (b - a) / max(a, b)
Davies-Bouldin Index

Rasio rata-rata cluster radius terhadap jarak antar centroid. Lebih kecil = lebih baik.

Calinski-Harabász (CH) Index

Rasio between-cluster vs within-cluster dispersion. Lebih besar = lebih baik.

External (dengan ground truth label)

Adjusted Rand Index (ARI) [-1, 1]

Kemiripan antara hasil clustering dengan label sebenarnya, terkoreksi random chance.

Normalized Mutual Information (NMI)

Mutual information ternormalisasi antara cluster dan label. Range [0, 1].

Fowlkes-Mallows Score

Geometric mean dari precision dan recall atas pasang titik dalam cluster yang sama.

Setup & Import

# Install jika belum ada: pip install scikit-learn matplotlib seaborn import numpy as np import matplotlib.pyplot as plt import seaborn as sns from sklearn.cluster import KMeans, DBSCAN, AgglomerativeClustering from sklearn.mixture import GaussianMixture from sklearn.preprocessing import StandardScaler from sklearn.metrics import silhouette_score, davies_bouldin_score from sklearn.datasets import make_blobs, make_moons, make_circles from scipy.cluster.hierarchy import dendrogram, linkage

Generate Dataset

# ---- Dataset 1: Blob clusters (cocok untuk K-Means) ---- X_blobs, y_blobs = make_blobs(n_samples=300, centers=4, cluster_std=0.8, random_state=42) # ---- Dataset 2: Two moons (cocok untuk DBSCAN) ---- X_moons, y_moons = make_moons(n_samples=300, noise=0.05, random_state=42) # ---- Dataset 3: Circles (cocok untuk DBSCAN) ---- X_circles, y_circles = make_circles(n_samples=300, noise=0.05, factor=0.5, random_state=42) # Normalisasi (PENTING untuk K-Means & DBSCAN) ---- scaler = StandardScaler() X_scaled = scaler.fit_transform(X_blobs)

K-Means

# ---- K-Means dengan K-Means++ init ---- kmeans = KMeans( n_clusters=4, init='k-means++', # lebih stabil n_init=10, # 10x restart max_iter=300, random_state=42 ) labels = kmeans.fit_predict(X_scaled) # Elbow Method untuk K optimal inertias = [] K_range = range(1, 11) for k in K_range: km = KMeans(n_clusters=k, random_state=42, n_init=10) km.fit(X_scaled) inertias.append(km.inertia_) plt.plot(K_range, inertias, 'bo-') plt.xlabel('K'); plt.ylabel('Inertia (WCSS)') plt.title('Elbow Method'); plt.show() # Evaluasi sil = silhouette_score(X_scaled, labels) db = davies_bouldin_score(X_scaled, labels) print(f"Silhouette: {sil:.3f}, DB Index: {db:.3f}")

DBSCAN

# ---- DBSCAN ---- dbscan = DBSCAN( eps=0.3, # radius neighborhood min_samples=5 # MinPts ) labels_db = dbscan.fit_predict(X_scaled) # -1 = noise/outlier n_clusters = len(set(labels_db)) - (1 if -1 in labels_db else 0) n_noise = list(labels_db).count(-1) print(f"Clusters: {n_clusters}, Noise: {n_noise}") # Mencari eps optimal dengan k-distance graph from sklearn.neighbors import NearestNeighbors nbrs = NearestNeighbors(n_neighbors=5).fit(X_scaled) distances, _ = nbrs.kneighbors(X_scaled) distances = np.sort(distances[:, -1]) plt.plot(distances) plt.ylabel('5th nearest distance') plt.title('K-Distance Graph (cari "siku")') plt.show()

Hierarchical Clustering + Dendrogram

# ---- Agglomerative Clustering ---- agg = AgglomerativeClustering( n_clusters=4, linkage='ward' # 'ward','complete','average','single' ) labels_agg = agg.fit_predict(X_scaled) # ---- Dendrogram dengan scipy ---- linkage_matrix = linkage(X_scaled[:50], method='ward') # sample kecil plt.figure(figsize=(12, 4)) dendrogram(linkage_matrix, truncate_mode='level', p=5) plt.title('Dendrogram') plt.xlabel('Data points') plt.ylabel('Distance') plt.show()

Gaussian Mixture Models

# ---- GMM ---- gmm = GaussianMixture( n_components=4, covariance_type='full', # 'full','tied','diag','spherical' n_init=5, random_state=42 ) gmm.fit(X_scaled) # Hard assignment labels_gmm = gmm.predict(X_scaled) # Soft assignment (probabilitas) probs = gmm.predict_proba(X_scaled) print("Probabilitas titik pertama:", probs[0]) # Model selection dengan BIC/AIC bics = [] for k in range(1, 10): g = GaussianMixture(n_components=k, random_state=42) g.fit(X_scaled) bics.append(g.bic(X_scaled)) # Pilih K dengan BIC minimum optimal_k = np.argmin(bics) + 1

Konseptual
1. Apa perbedaan utama antara supervised learning (klasifikasi) dan unsupervised learning (clustering)? Berikan contoh algoritma masing-masing dan jelaskan kapan masing-masing digunakan.
▾
Supervised Learning (Klasifikasi): Memerlukan data berlabel (training set dengan class label). Model belajar memetakan input → output berdasarkan contoh. Algoritma: Decision Tree, SVM, Neural Network, Naive Bayes. Digunakan saat kita punya data berlabel dan ingin memprediksi kategori data baru.

Unsupervised Learning (Clustering): Tidak memerlukan label. Model menemukan struktur/pola tersembunyi dari data itu sendiri. Algoritma: K-Means, DBSCAN, Hierarchical, GMM. Digunakan saat tidak ada label, atau ingin eksplorasi data, atau menemukan segmen alami dalam data.
K-Means Hitung Manual
2. Diberikan 6 titik: A(1,1), B(2,1), C(1,2), D(8,8), E(9,8), F(8,9). Lakukan K-Means dengan K=2, centroid awal C₁=(1,1) dan C₂=(8,8). Tunjukkan hasil iterasi pertama dan kedua hingga konvergen.
▾
Iterasi 1 — Assignment:
Euclidean distance ke C₁(1,1): A=0, B=1, C=1, D=9.90, E=10.63, F=10.63
Euclidean distance ke C₂(8,8): A=9.90, B=9.22, C=9.22, D=0, E=1, F=1
→ Cluster 1: {A, B, C}  |  Cluster 2: {D, E, F}

Iterasi 1 — Update Centroid:
C₁ baru = ((1+2+1)/3, (1+1+2)/3) = (1.33, 1.33)
C₂ baru = ((8+9+8)/3, (8+8+9)/3) = (8.33, 8.33)

Iterasi 2 — Assignment (dengan centroid baru):
Jarak A(1,1) ke C₁(1.33,1.33) = 0.47  |  ke C₂(8.33,8.33) = 10.37 → Cluster 1
Semua titik tetap di cluster yang sama → Konvergen! Tidak ada perubahan assignment.
DBSCAN Analisis
3. Mengapa DBSCAN lebih unggul dari K-Means untuk mendeteksi cluster berbentuk cincin (ring-shaped) atau bulan sabit (crescent)? Jelaskan secara matematis dan intuitif.
▾
Intuitif: K-Means menetapkan setiap titik ke centroid TERDEKAT. Cluster cincin memiliki centroid di tengah lingkaran — area yang kosong! K-Means akan salah mempartisi titik-titik di cincin ke "sisi" yang berbeda berdasarkan jarak ke centroid.

Matematis: Objective K-Means J = Σ||x - μₖ||² mengasumsikan cluster berbentuk convex dan bulat (isotropic). Bentuk cincin tidak convex — tidak ada centroid yang mewakilinya dengan baik.

DBSCAN: Bekerja berdasarkan kepadatan lokal: menghubungkan titik yang saling berdekatan dalam radius ε. Titik-titik di sepanjang cincin saling terhubung karena setiap titik memiliki tetangga yang cukup dekat. Algoritma "merangkak" mengikuti kepadatan tanpa asumsi bentuk cluster tertentu.
Evaluasi
4. Jelaskan Silhouette Score: rumus, interpretasi nilai, dan bagaimana kamu menggunakannya untuk memilih K optimal di K-Means. Apa keterbatasannya?
▾
Rumus: s(i) = (b(i) - a(i)) / max(a(i), b(i))
• a(i) = rata-rata jarak titik i ke semua titik DALAM clusternya (cohesion)
• b(i) = rata-rata jarak titik i ke semua titik di cluster TETANGGA terdekat (separation)

Interpretasi:
• s ≈ +1: titik berada sangat jauh dari cluster lain → clustering sangat baik
• s ≈ 0: titik berada di perbatasan antar cluster
• s ≈ -1: titik kemungkinan salah cluster

Memilih K: Hitung rata-rata Silhouette Score untuk K=2..10. Pilih K dengan skor tertinggi.

Keterbatasan: (1) Mahal secara komputasi O(n²). (2) Bisa bias terhadap cluster berbentuk konveks. (3) Tidak cocok untuk data berdimensi sangat tinggi.
Studi Kasus
5. Startup e-commerce ingin segmentasi 500.000 pelanggan berdasarkan: frekuensi beli/bulan, total pengeluaran, kategori produk favorit, dan waktu aktif. Algoritma apa yang kamu rekomendasikan? Jelaskan langkah preprocessing dan validasi.
▾
Rekomendasi: K-Means (skala besar) atau GMM (analisis mendalam)

Preprocessing:
1. Handle missing values (imputation median/modus)
2. Encode kategori (One-Hot Encoding untuk kategori produk)
3. Standardisasi wajib: StandardScaler() — frekuensi (0-30) dan pengeluaran (0-10jt) berbeda skala
4. Optionally: PCA untuk reduksi dimensi jika >20 fitur

Pemilihan K: Gunakan Elbow Method + Silhouette Score. Ekspektasi 4-6 segmen (misal: loyal high-spender, occasional buyer, bargain hunter, new user).

Validasi bisnis: Beri nama setiap cluster, pastikan segmen masuk akal secara bisnis. Gunakan cluster sebagai input untuk strategi marketing berbeda.
Pemrograman
6. Tulis kode Python lengkap: load dataset Iris (sklearn.datasets.load_iris), lakukan K-Means dengan K=3, visualisasikan cluster dalam 2D menggunakan PCA, dan cetak Silhouette Score.
▾
from sklearn.datasets import load_iris
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt
import numpy as np

# Load data
iris = load_iris()
X = iris.data # 150 sampel, 4 fitur

# Preprocessing
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# K-Means
kmeans = KMeans(n_clusters=3, init='k-means++', n_init=10, random_state=42)
labels = kmeans.fit_predict(X_scaled)

# Evaluasi
sil = silhouette_score(X_scaled, labels)
print(f"Silhouette Score: {sil:.4f}")

# Visualisasi dengan PCA 2D
pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_scaled)

plt.figure(figsize=(8, 6))
colors = ['#1D9E75', '#EF9F27', '#378ADD']
for i in range(3):
    mask = labels == i
    plt.scatter(X_2d[mask, 0], X_2d[mask, 1],
                c=colors[i], label=f'Cluster {i+1}', alpha=0.7)
plt.title(f'K-Means Iris (Silhouette={sil:.3f})')
plt.xlabel('PC1'); plt.ylabel('PC2')
plt.legend(); plt.show()
