Motivasi

Mengapa CNN?

Neural network biasa (Fully Connected / Dense) memperlakukan gambar sebagai vektor 1D yang panjang. Gambar 224×224×3 = 150.528 input neuron — sangat boros parameter dan tidak memanfaatkan struktur spasial gambar.

CNN memecahkan ini dengan tiga ide kunci: local receptive field, parameter sharing, dan hierarchical feature learning.

Operasi Konvolusi
Inti dari CNN — bagaimana filter mendeteksi fitur dalam gambar
Definisi Matematis

Konvolusi 2D

Operasi konvolusi menggeser sebuah filter/kernel kecil di atas input, mengalikan elemen-per-elemen, dan menjumlahkan hasilnya menjadi satu nilai dalam feature map.

S(i,j) = (I * K)(i,j) = Σₘ Σₙ I(i+m, j+n) · K(m,n)

I = input image, K = kernel/filter, S = feature map

💡 Satu filter mendeteksi satu jenis fitur (misalnya tepi vertikal). CNN punya banyak filter, tiap filter belajar fitur yang berbeda.

Ukuran Output Feature Map

Output = ⌊(N + 2P - F) / S⌋ + 1

N = ukuran input, F = ukuran filter, P = padding, S = stride

Bagian Feature Extraction

Conv Layer

Mengaplikasikan N filter untuk menghasilkan N feature map. Mendeteksi pola lokal: tepi, sudut, tekstur, warna.

Batch Norm (opsional)

Normalisasi output setiap layer → training lebih stabil dan cepat.

Activation (ReLU)

Menambah non-linearitas: f(x) = max(0, x). Mengatasi vanishing gradient.

Pooling Layer

Mengurangi ukuran spasial (downsampling) → lebih sedikit parameter, translasi invariant.

Bagian Classification

Flatten

Mengubah tensor 3D (H×W×C) menjadi vektor 1D. Jembatan antara konvolusi dan dense layer.

Dense / FC Layer

Fully connected — setiap neuron terhubung ke semua input. Belajar kombinasi fitur tingkat tinggi.

Dropout (regularisasi)

Menonaktifkan sebagian neuron secara acak saat training → mencegah overfitting.

Softmax (output)

Mengubah logit menjadi probabilitas — jumlah semua kelas = 1.

σ(z)ᵢ = eᶻⁱ / Σⱼ eᶻʲ

Pooling Layer

Jenis Pooling

Pooling mengurangi ukuran spasial feature map, mengurangi jumlah parameter, dan membuat representasi lebih robust terhadap translasi kecil.

Max Pooling ⭐ (paling umum)

Ambil nilai MAXIMUM dari setiap window. Menangkap fitur yang paling menonjol.

Output = max(window)
Average Pooling

Rata-rata nilai dalam window. Lebih halus, sering dipakai di layer akhir.

Global Average Pooling (GAP)

Rata-rata seluruh feature map → satu nilai per channel. Menggantikan Flatten di arsitektur modern.

Loss Function

Mengukur Kesalahan

Categorical Cross-Entropy (multi-class)
L = -Σᵢ yᵢ · log(ŷᵢ)

Standar untuk klasifikasi multi-kelas dengan Softmax output

Binary Cross-Entropy (2 kelas)
L = -(y·log(ŷ) + (1-y)·log(1-ŷ))
Mean Squared Error (regresi)
L = (1/n) · Σ(y - ŷ)²
Backpropagation

Cara CNN Belajar

1

Forward pass — hitung prediksi dari input ke output

2

Hitung loss — bandingkan prediksi dengan label sebenarnya

3

Backward pass — hitung gradien loss terhadap tiap weight (chain rule)

4

Update weights — geser weight berlawanan arah gradien

w ← w - η · ∂L/∂w

η = learning rate

Load & Preprocessing Dataset CIFAR-10

# ---- Load CIFAR-10 (10 kelas: pesawat, mobil, burung, kucing, dll) ---- (X_train, y_train), (X_test, y_test) = keras.datasets.cifar10.load_data() print(f"Train: {X_train.shape}") # (50000, 32, 32, 3) print(f"Test : {X_test.shape}") # (10000, 32, 32, 3) # ---- Normalisasi pixel ke [0, 1] ---- X_train = X_train.astype('float32') / 255.0 X_test = X_test.astype('float32') / 255.0 # ---- One-hot encoding label ---- y_train_oh = keras.utils.to_categorical(y_train, 10) y_test_oh = keras.utils.to_categorical(y_test, 10) CLASS_NAMES = ['airplane','automobile','bird','cat','deer', 'dog','frog','horse','ship','truck'] # ---- Data Augmentation ---- data_augmentation = keras.Sequential([ layers.RandomFlip('horizontal'), layers.RandomRotation(0.1), layers.RandomZoom(0.1), ])

Bangun Model CNN

def build_cnn(input_shape=(32,32,3), num_classes=10): model = models.Sequential([ # ==== Block 1 ==== layers.Conv2D(32, (3,3), padding='same', input_shape=input_shape), layers.BatchNormalization(), layers.Activation('relu'), layers.Conv2D(32, (3,3), padding='same'), layers.BatchNormalization(), layers.Activation('relu'), layers.MaxPooling2D((2,2)), layers.Dropout(0.25), # ==== Block 2 ==== layers.Conv2D(64, (3,3), padding='same'), layers.BatchNormalization(), layers.Activation('relu'), layers.Conv2D(64, (3,3), padding='same'), layers.BatchNormalization(), layers.Activation('relu'), layers.MaxPooling2D((2,2)), layers.Dropout(0.25), # ==== Classifier ==== layers.Flatten(), layers.Dense(512, activation='relu'), layers.BatchNormalization(), layers.Dropout(0.5), layers.Dense(num_classes, activation='softmax'), ]) return model model = build_cnn() model.summary()

Compile, Train & Evaluate

# ---- Compile ---- model.compile( optimizer=keras.optimizers.Adam(learning_rate=0.001), loss='categorical_crossentropy', metrics=['accuracy'] ) # ---- Callbacks ---- callbacks = [ keras.callbacks.EarlyStopping( patience=10, restore_best_weights=True ), keras.callbacks.ReduceLROnPlateau( factor=0.5, patience=5, min_lr=1e-6 ), keras.callbacks.ModelCheckpoint( 'best_model.h5', save_best_only=True ) ] # ---- Train ---- history = model.fit( X_train, y_train_oh, batch_size=64, epochs=50, validation_split=0.2, callbacks=callbacks, verbose=1 ) # ---- Evaluate ---- test_loss, test_acc = model.evaluate(X_test, y_test_oh) print(f"\nTest accuracy: {test_acc:.4f}") # ---- Predict ---- predictions = model.predict(X_test[:10]) pred_classes = np.argmax(predictions, axis=1) print([CLASS_NAMES[i] for i in pred_classes])

Latihan & Diskusi
Klik soal untuk lihat jawaban — 7 soal dari konseptual hingga coding
Konseptual
1. Jelaskan 3 keunggulan CNN dibanding fully-connected network untuk data gambar. Apa yang dimaksud dengan "parameter sharing" dan "translation invariance"?
▾
3 Keunggulan CNN:
1. Parameter Sharing: Satu filter (misal 3×3 = 9 parameter) digunakan di seluruh gambar. FC network butuh satu weight per koneksi — untuk gambar 32×32×3, layer pertama butuh hingga ratusan ribu weight. CNN butuh hanya ribuan.

2. Sparse Connectivity (Local Receptive Field): Setiap neuron di feature map hanya "melihat" area kecil input (misal 3×3 piksel), bukan seluruh gambar. Ini mencerminkan cara kita memproses gambar: fitur lokal seperti tepi ada di area kecil.

3. Translation Invariance: Karena parameter sharing, filter yang mendeteksi "tepi vertikal" akan bekerja sama baik di posisi gambar mana pun. Kucing di sudut kiri atas dan sudut kanan bawah akan sama-sama terdeteksi.
Hitung Manual
2. Input gambar 6×6, filter 3×3, stride=1, padding=0. Berapa ukuran output feature map? Berapa jumlah operasi multiply-add yang dilakukan?
▾
Ukuran output:
Output = ⌊(N + 2P - F) / S⌋ + 1 = ⌊(6 + 0 - 3) / 1⌋ + 1 = 3 + 1 = 4×4 = 16 elemen

Jumlah operasi multiply-add:
Setiap posisi filter → 3×3 = 9 multiply-add
Jumlah posisi = 4×4 = 16
Total = 16 × 9 = 144 operasi

Jika ada 32 filter: 144 × 32 = 4.608 operasi (masih sangat efisien!)

Training
4. Apa itu vanishing gradient problem dan mengapa ReLU lebih baik dari Sigmoid untuk layer dalam CNN? Jelaskan dengan persamaan turunan masing-masing.
▾
Vanishing Gradient: Selama backpropagation, gradien dikalikan di setiap layer (chain rule). Jika gradien kecil (<1), perkalian berulang → gradien hampir nol di layer awal → layer awal tidak belajar.

Sigmoid: σ'(x) = σ(x)(1-σ(x)) — maksimum hanya 0.25 (saat x=0). Untuk 10 layer: 0.25¹⁰ ≈ 0.000001 → vanishing!

ReLU: f'(x) = 1 jika x > 0, 0 jika x ≤ 0. Untuk x positif, gradiennya tetap 1 → tidak "mengecil" saat dilalui. Namun ada masalah "dying ReLU" — neuron yang outputnya selalu 0 tidak pernah update. Solusi: Leaky ReLU.
Arsitektur
5. Untuk klasifikasi citra sampah organik vs anorganik (2 kelas, dataset kecil ~500 gambar), apakah lebih baik train dari scratch atau transfer learning? Pilih base model, jelaskan alasannya.

Rekomendasi: Transfer Learning dengan MobileNetV2

Alasan:
1. Dataset 500 gambar sangat kecil untuk training dari scratch — pasti overfitting
2. Gambar sampah masih termasuk objek visual alami yang mirip ImageNet
3. MobileNetV2 dipilih karena: ringan (3.4M params), cepat, dan akurasi cukup baik

Langkah:
1. Load MobileNetV2 (include_top=False, weights='imagenet')
2. Freeze semua layer base
3. Tambah: GlobalAveragePooling → Dropout(0.3) → Dense(1, activation='sigmoid')
4. Compile dengan binary_crossentropy + Adam(0.001)
5. Augmentasi: flip, rotate, zoom untuk perbanyak data
6. Train 20-30 epoch, monitor val_accuracy
7. Ekspektasi akurasi: 85-92% meski dataset kecil
Analisis
6. Training CNN menunjukkan train_acc=95% tapi val_acc=60%. Apa masalahnya? Sebutkan minimal 4 solusi teknis yang bisa diterapkan.
▾
Masalah: OVERFITTING — model hafal data training tapi gagal generalisasi.

Solusi:
1. Data Augmentation: flip, rotate, crop, color jitter → model melihat lebih banyak variasi
2. Dropout: tambah Dropout(0.4-0.5) setelah Dense layer — paksa model tidak bergantung pada neuron tertentu
3. L2 Regularization: tambah kernel_regularizer=l2(0.001) pada layer Conv/Dense
4. Early Stopping: hentikan training saat val_loss tidak membaik (patience=10)
5. Kurangi kapasitas model: kurangi jumlah filter atau layer — model terlalu kompleks untuk data
6. Perbanyak data: kumpulkan lebih banyak gambar training
Coding
7. Tulis kode Python lengkap: bangun CNN sederhana untuk MNIST (angka 0-9, grayscale 28×28), compile, train 5 epoch, dan tampilkan confusion matrix.
▾
import tensorflow as tf from tensorflow.keras import layers, models import numpy as np import matplotlib.pyplot as plt from sklearn.metrics import confusion_matrix import seaborn as sns # Load MNIST (X_train, y_train), (X_test, y_test) = tf.keras.datasets.mnist.load_data() X_train = X_train[..., np.newaxis] / 255.0 # (60000,28,28,1) X_test = X_test[..., np.newaxis] / 255.0 # Bangun model model = models.Sequential([ layers.Conv2D(32, (3,3), activation='relu', input_shape=(28,28,1)), layers.MaxPooling2D((2,2)), layers.Conv2D(64, (3,3), activation='relu'), layers.MaxPooling2D((2,2)), layers.Flatten(), layers.Dense(64, activation='relu'), layers.Dropout(0.5), layers.Dense(10, activation='softmax'), ]) model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy']) history = model.fit(X_train, y_train, epochs=5, validation_split=0.1, batch_size=64) # Evaluasi test_loss, test_acc = model.evaluate(X_test, y_test) print(f"\nTest accuracy: {test_acc:.4f}") # ekspektasi ~99% # Confusion Matrix y_pred = np.argmax(model.predict(X_test), axis=1) cm = confusion_matrix(y_test, y_pred) plt.figure(figsize=(10,8)) sns.heatmap(cm, annot=True, fmt='d', cmap='Blues') plt.title('Confusion Matrix MNIST CNN') plt.xlabel('Predicted'); plt.ylabel('Actual') plt.show()
