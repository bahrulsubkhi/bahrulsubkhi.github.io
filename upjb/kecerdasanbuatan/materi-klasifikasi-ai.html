Klasifikasi pada Artificial Intelligence

Naive Bayes, Decision Tree, dan Support Vector Machine

Pendahuluan

Klasifikasi merupakan salah satu metode dalam Machine Learning yang digunakan untuk memprediksi kategori atau kelas dari suatu data berdasarkan pola yang telah dipelajari sebelumnya.

Dalam klasifikasi, model dilatih menggunakan data yang memiliki label kemudian digunakan untuk memprediksi data baru.

Spam Detection

Menentukan email spam atau bukan spam.

Diagnosa Penyakit

Prediksi penyakit berdasarkan gejala pasien.

Analisis Sentimen

Klasifikasi sentimen positif dan negatif.

1. Naive Bayes

Naive Bayes adalah algoritma klasifikasi berbasis probabilitas yang menggunakan Teorema Bayes dengan asumsi setiap fitur bersifat independen.

Rumus Naive Bayes:
P(H|X) = ( P(X|H) × P(H) ) / P(X)
Kelebihan
  • Cepat dan sederhana
  • Efektif untuk klasifikasi teks
  • Cocok untuk dataset besar
Kekurangan
  • Asumsi independensi fitur tidak selalu realistis
  • Sensitif terhadap missing value

2. Decision Tree

Decision Tree merupakan algoritma klasifikasi berbentuk pohon keputusan. Setiap node merepresentasikan atribut dan leaf merepresentasikan hasil klasifikasi.

Entropy:
Entropy(S) = -Σ pi log2 pi
Information Gain:
Gain(S,A) = Entropy(S) - Σ ( |Sv| / |S| ) Entropy(Sv)
Kelebihan
  • Mudah dipahami
  • Mudah divisualisasikan
  • Tidak memerlukan normalisasi data
Kekurangan
  • Rentan overfitting
  • Sensitif terhadap perubahan data kecil

3. Support Vector Machine (SVM)

Support Vector Machine adalah algoritma klasifikasi yang bekerja dengan mencari hyperplane terbaik untuk memisahkan data antar kelas.

Persamaan Hyperplane:
w · x + b = 0
Kelebihan
  • Akurasi tinggi
  • Efektif untuk data berdimensi tinggi
  • Baik untuk klasifikasi kompleks
Kekurangan
  • Training lebih lambat
  • Sulit dipahami pemula
  • Tidak cocok untuk dataset sangat besar

Perbandingan Algoritma

Algoritma Kelebihan Kekurangan
Naive Bayes Cepat dan sederhana Asumsi independensi fitur
Decision Tree Mudah dipahami Overfitting
SVM Akurasi tinggi Training lambat

Kesimpulan

Klasifikasi merupakan teknik penting dalam Artificial Intelligence untuk memprediksi kategori data.

Pemilihan algoritma tergantung pada jenis data, ukuran dataset, dan tingkat akurasi yang diinginkan.
