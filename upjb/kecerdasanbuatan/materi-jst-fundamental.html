❓ Motivasi

Mengapa Kita Butuh JST?

Kamu sudah tahu Decision Tree, Naive Bayes, dan SVM. Mereka bekerja baik — tapi ada masalah yang mereka kesulitan selesaikan: pola yang sangat kompleks dan non-linear.

Contoh Nyata: Filter Foto Profil

Instagram ingin otomatis mendeteksi apakah foto yang diunggah mengandung wajah manusia atau bukan. Input-nya adalah jutaan piksel. Setiap piksel punya nilai 0–255. Batas keputusan yang memisahkan "ada wajah" vs "tidak ada wajah" tidak mungkin berupa garis atau hyperplane lurus.

💡

Masalah inti: Semakin kompleks pola dalam data (gambar, suara, teks), semakin kita butuh model yang mampu membentuk batas keputusan yang sangat fleksibel — bukan hanya garis lurus.

Keterbatasan Model Linear

Coba perhatikan masalah XOR sederhana. Empat titik, dua kelas — tapi tidak ada satu garis pun yang bisa memisahkan mereka dengan benar:

Garis lurus apapun tidak bisa memisahkan ✅ dari ❌ pada masalah XOR — ini yang memotivasi JST.

Solusinya: Tambahkan "Lapisan Pikir"

JST menambahkan lapisan tersembunyi (hidden layer) yang mentransformasi data ke representasi baru di mana masalah jadi lebih mudah dipisahkan. Analoginya: kamu tidak langsung menjawab soal sulit — kamu berpikir beberapa langkah dulu.

🎓

Pengenalan tulisan tangan

Gambar 28×28 piksel → prediksi angka 0–9. Pola tiap orang berbeda tapi JST bisa generalisasi.

📧

Filter spam email

Ribuan kombinasi kata, pengirim, pola waktu → keputusan: spam atau bukan.

🏥

Diagnosis medis

Nilai lab, usia, riwayat → prediksi risiko penyakit. Pola multi-variabel kompleks.

🎵

Rekomendasi lagu

Riwayat dengar + mood + waktu → lagu yang "pas". Tidak ada rumus matematika sederhana untuk ini.

🧠 Satu Neuron

Mulai dari Satu Neuron Dulu

Jangan langsung ke jaringan. Pahami dulu satu neuron tiruan — unit terkecil JST.

Neuron Biologis vs Tiruan — Secara Intuitif

🧬 Neuron di otak kamu

Ketika kamu melihat foto makanan enak, ribuan neuron menerima sinyal visual, memprosesnya, dan memutuskan: "aku lapar". Setiap neuron menerima sinyal, menimbang kepentingannya, lalu mengirim sinyal baru jika cukup kuat.

🤖 Neuron tiruan (kita buat)

Sama prinsipnya. Menerima beberapa angka (input), mengalikan tiap angka dengan "bobot kepentingan" (weight), menjumlahkannya, lalu memutuskan apakah hasilnya cukup besar untuk diteruskan.

Anatomi Satu Neuron

Dalam 1 neuron, hanya ada tiga hal:

  1. Input (x) — angka yang masuk. Bisa satu atau banyak.
  2. Bobot (w) — seberapa "penting" tiap input.
  3. Output — hasil komputasi, diteruskan ke neuron berikutnya.

Versi Paling Sederhana: 1 Input, 1 Bobot

Misalnya: kita ingin prediksi nilai UAS (output) dari jumlah jam belajar (input).

output = w × x
Contoh: jam belajar x=5, bobot w=8 → output = 8 × 5 = 40

Bobot w=8 artinya "setiap 1 jam belajar, nilai naik 8 poin". Sederhana — ini pada dasarnya regresi linear. Tapi ini titik awal kita.

💡

Ingat dari ML dasar: Ini persis seperti koefisien di regresi linear! JST dimulai dari sini, lalu kita susun banyak neuron berlapis untuk menangkap pola lebih kompleks.

⚖️ Bobot & Bias

Memahami Bobot dan Bias

Analogi Nyata: Memilih Tempat Makan

Kamu akan memilih: pergi ke warung bakso atau tidak. Ada tiga faktor:

Input & Bobot (kepentingan):

  • x₁ = Harga murah? (0/1) → w₁ = 0.3 (agak penting)
  • x₂ = Dekat dari kos? (0/1) → w₂ = 0.5 (penting)
  • x₃ = Lagi lapar banget? (0/1) → w₃ = 0.8 (sangat penting)

Skenario hari ini:

  • Harga murah: x₁ = 1 ✅
  • Dekat kos: x₂ = 0 ❌ (agak jauh)
  • Lapar banget: x₃ = 1 ✅

Total skor = ?

Hitung z = w₁x₁ + w₂x₂ + w₃x₃
z = (0.3 × 1) + (0.5 × 0) + (0.8 × 1)
z = 0.3 + 0.0 + 0.8
z = 1.1 → cukup tinggi → pergi ke bakso! 🍜

Apa itu Bias?

Bayangkan kamu orangnya susah keluar kos — butuh skor lebih tinggi dari rata-rata baru mau pergi. Atau sebaliknya, kamu selalu lapar sehingga threshold-mu rendah. Inilah fungsi bias (b): menggeser titik keputusan.

z = w₁x₁ + w₂x₂ + w₃x₃ + b Jika b = −0.5 (susah keluar): z = 1.1 + (−0.5) = 0.6 → skor turun, lebih susah "aktif" Jika b = +0.3 (selalu lapar): z = 1.1 + 0.3 = 1.4 → lebih mudah "aktif"
✅

Kesimpulan: Bobot (w) = seberapa penting tiap input. Bias (b) = menggeser ambang keputusan. Keduanya adalah parameter yang dipelajari oleh model dari data.

Contoh dengan 2 Input — Hitungan Tangan

Prediksi apakah mahasiswa lulus (1) atau tidak (0) berdasarkan nilai UTS dan kehadiran:

DataNilai UTS (x₁)Kehadiran (x₂)Label
Mahasiswa A0.80.9Lulus (1)
Mahasiswa B0.30.4Tidak Lulus (0)
Mahasiswa C0.60.2Tidak Lulus (0)

Misalkan model punya: w₁ = 0.7, w₂ = 0.5, b = −0.5

Mahasiswa A:
z = (0.7 × 0.8) + (0.5 × 0.9) + (−0.5) = 0.56 + 0.45 − 0.5
z = 0.51 → positif → prediksi: Lulus ✅
Mahasiswa B:
z = (0.7 × 0.3) + (0.5 × 0.4) + (−0.5) = 0.21 + 0.20 − 0.5
z = −0.09 → negatif → prediksi: Tidak Lulus ✅
⚡ Aktivasi

Fungsi Aktivasi — Mengapa Perlu?

Masalah Tanpa Aktivasi

Coba pikirkan: kalau kita susun 3 layer neuron tanpa fungsi aktivasi:

Layer 1:   a = W₁ · x + b₁
Layer 2:   output = W₂ · a + b₂ = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂) ⚠️ Hasilnya tetap linear! Berapapun layer yang kita tambah, sama saja dengan 1 layer linear.
⚠️

Tanpa fungsi aktivasi, JST sedalam apapun = regresi linear biasa. Fungsi aktivasi-lah yang memberi kemampuan non-linear — memungkinkan JST mempelajari pola kompleks.

Analogi: Lampu dengan Dimmer vs Saklar On/Off

🔘 Saklar On/Off (Step Function)

Jika z > 0 → output = 1 (nyala). Jika z ≤ 0 → output = 0 (mati). Keras, tidak ada gradien — tidak bisa belajar.

🎚️ Dimmer (Sigmoid / ReLU)

Output bisa bernilai antara 0–1 (sigmoid) atau 0–∞ (ReLU). Ada gradien → model bisa belajar dari kesalahan.

Tiga Fungsi Aktivasi Utama yang Perlu Diketahui

f(z) = max(0, z)
FungsiRumusOutputKapan dipakai
Sigmoid1 / (1 + e⁻ᶻ)0 sampai 1Output layer — prediksi probabilitas biner (ya/tidak)
ReLU ⭐max(0, z)0 atau positifHidden layer — default terbaik, cepat, sederhana
Softmaxeᶻⁱ / ΣeᶻʲDistribusi probabilitasOutput layer — prediksi multi-kelas (A/B/C/...)
✅

Panduan praktis: Untuk tugas kamu sehari-hari — gunakan ReLU di semua hidden layer. Gunakan Sigmoid kalau output-nya ya/tidak. Gunakan Softmax kalau output-nya pilihan dari banyak kelas.

Contoh Hitungan Sigmoid

Dari contoh sebelumnya, z = 0.51 (Mahasiswa A). Kalau kita pakai sigmoid:

sigmoid(0.51) = 1 / (1 + e⁻⁰·⁵¹) = 1 / (1 + 0.601) = 1 / 1.601
= 0.625 → interpretasi: "62.5% kemungkinan lulus"
🕸️ Jaringan

Menyusun Banyak Neuron Menjadi Jaringan

Sekarang kita susun neuron-neuron menjadi lapisan (layer). Konsepnya sederhana: output satu neuron menjadi input neuron berikutnya.

Struktur Dasar

📥

Input Layer

Satu neuron per fitur. Hanya meneruskan data — tidak ada komputasi. Jika fiturmu ada 3, input layer-nya 3 neuron.

🔀

Hidden Layer

Di sinilah "keajaiban" terjadi. Tiap neuron belajar mendeteksi satu pola spesifik dari data. Semakin banyak neuron → pola yang bisa dipelajari makin kompleks.

📤

Output Layer

Menghasilkan prediksi akhir. Jumlah neuron = jumlah kelas yang diprediksi (atau 1 untuk biner/regresi).

💡

Perlu berapa hidden layer? Untuk kebanyakan masalah tabular (data tabel), 1–2 hidden layer sudah cukup. Deep learning (banyak layer) diperlukan untuk gambar, suara, dan teks.

Hitung Jumlah Parameter

Tiap koneksi antar neuron = 1 bobot. Tiap neuron = 1 bias. Total parameter jaringan 3→4→2:

Layer Input→Hidden: 3 neuron × 4 neuron = 12 bobot + 4 bias = 16
Layer Hidden→Output: 4 neuron × 2 neuron = 8 bobot + 2 bias = 10
Total parameter = 26 — semua ini yang "dipelajari" dari data
➡️ Forward Pass

Aliran Data: Forward Pass

Forward pass = proses mengalirkan data dari input ke output untuk menghasilkan prediksi. Mari kita ikuti langkah demi langkah dengan angka nyata.

Kasus: Prediksi Nilai Akhir Mahasiswa

Input: x₁ = nilai UTS (0.7), x₂ = kehadiran (0.8). Jaringan: 2 input → 2 hidden → 1 output.

Bobot yang sudah "dilatih": W₁₁=0.5, W₁₂=0.3, W₂₁=0.4, W₂₂=0.6, b₁=0.1, b₂=−0.1
Bobot output: v₁=0.8, v₂=0.7, b_out=0.05 | Fungsi aktivasi: ReLU (hidden), Sigmoid (output)

1

Hitung input berbobot untuk Hidden Neuron 1 (h₁)

z₁ = W₁₁×x₁ + W₂₁×x₂ + b₁ = (0.5×0.7) + (0.4×0.8) + 0.1
= 0.35 + 0.32 + 0.1 = 0.77
h₁ = ReLU(0.77) = max(0, 0.77) = 0.77
2

Hitung input berbobot untuk Hidden Neuron 2 (h₂)

z₂ = W₁₂×x₁ + W₂₂×x₂ + b₂ = (0.3×0.7) + (0.6×0.8) + (−0.1)
= 0.21 + 0.48 − 0.10 = 0.59
h₂ = ReLU(0.59) = 0.59
3

Hitung output akhir (ŷ)

z_out = v₁×h₁ + v₂×h₂ + b_out = (0.8×0.77) + (0.7×0.59) + 0.05
= 0.616 + 0.413 + 0.05 = 1.079
ŷ = Sigmoid(1.079) = 1/(1+e⁻¹·⁰⁷⁹) ≈ 0.746
4

Interpretasi hasil

ŷ = 0.746 artinya model memprediksi 74.6% kemungkinan lulus. Kalau threshold 0.5, maka prediksi = Lulus.

📉 Loss

Mengukur Kesalahan — Fungsi Loss

Setelah model membuat prediksi, kita perlu mengukur: seberapa jauh prediksi dari jawaban benar? Inilah fungsi loss.

Analogi: Nilai Ujian vs Prediksi Guru

Bayangkan guru memprediksi nilai kamu 85, ternyata nilai aslinya 70. Kesalahannya = 15. Kalau prediksi = 68, kesalahannya = 2. Kita ingin model yang kesalahannya sekecil mungkin.

MSE — Mean Squared Error (untuk Regresi)

MSE = (1/n) × Σ (y − ŷ)² y = nilai asli, ŷ = prediksi model, n = jumlah data Dikuadratkan supaya: (1) tidak ada nilai negatif, (2) error besar dihukum lebih berat

Contoh dengan 3 data:

Prediksi: [80, 75, 90] | Asli: [85, 70, 88]
MSE = [(80−85)² + (75−70)² + (90−88)²] / 3
= [25 + 25 + 4] / 3 = 54 / 3
MSE = 18.0

Binary Cross-Entropy (untuk Klasifikasi Biner)

BCE = −(1/n) × Σ [y·log(ŷ) + (1−y)·log(1−ŷ)] Dipakai saat output adalah probabilitas (0–1). Menghukum berat prediksi yang sangat yakin tapi salah.

Contoh 1 data: y=1 (lulus), ŷ=0.746 (prediksi tadi):

BCE = −[1×log(0.746) + 0×log(0.254)]
= −[1×(−0.293) + 0] = −(−0.293)
BCE = 0.293 ← semakin kecil, semakin baik
💡

Tujuan training: Cari nilai bobot (w) dan bias (b) yang membuat loss sekecil mungkin. Inilah yang dimaksud "model belajar dari data".

Bagaimana Model Belajar?

Intuisi: Turun Bukit dengan Mata Tertutup

Bayangkan kamu berada di pegunungan berkabut — tidak bisa lihat keseluruhan medan. Tugasmu: sampai ke lembah (titik loss terendah). Caranya: rasakan kemiringan tanah di kakimu, lalu melangkah ke arah yang lebih rendah.

📐 Kemiringan tanah = gradient (turunan loss terhadap bobot)
👟 Satu langkah = satu kali update bobot
📏 Panjang langkah = learning rate (α)
🏔️ Sampai lembah = loss minimum = model optimal

Rumus Update Bobot — Gradient Descent

w_baru = w_lama − α × (∂Loss/∂w) α = learning rate (biasanya 0.001–0.01) | ∂Loss/∂w = gradien: arah & kecepatan perubahan loss Tanda minus (−) artinya kita bergerak berlawanan arah gradient → menuju minimum

Contoh Hitungan Manual — 1 Langkah Update

Misalkan: w=0.3, α=0.1, dan kita hitung gradien loss terhadap w = 0.8

w_baru = 0.3 − (0.1 × 0.8)
= 0.3 − 0.08
w_baru = 0.22 → bobot bergerak menuju nilai yang mengurangi loss

Learning Rate — Seberapa Besar Langkahnya?

🐌 Terlalu kecil (α = 0.0001)

Perlu sangat banyak langkah. Training sangat lambat. Bisa terjebak di lokal minimum.

🐇 Terlalu besar (α = 10)

Langkah terlalu lebar — "melompati" lembah dan terus melambung. Loss malah naik terus (divergen).

🎮 Simulasi Gradient Descent

Backpropagation — Bagaimana Gradien Dihitung?

Backpropagation adalah cara efisien menghitung gradien untuk setiap bobot di jaringan menggunakan chain rule kalkulus. Caranya:

1

Forward pass

Hitung prediksi ŷ dari input hingga output, simpan semua nilai aktivasi di tiap layer.

2

Hitung loss

Bandingkan ŷ dengan y asli menggunakan fungsi loss (MSE/BCE).

3

Backward pass

Hitung gradien dari output ke input, layer per layer, menggunakan chain rule. Gradien mengalir mundur.

4

Update semua bobot

Perbarui setiap bobot dan bias menggunakan rumus gradient descent.

5

Ulangi (epoch)

Proses 1–4 diulang untuk seluruh data training berkali-kali (ratusan–ribuan epoch) sampai loss konvergen.

✅

Kabar baiknya: Kamu tidak perlu menghitung gradien manual. Framework seperti TensorFlow/Keras dan PyTorch melakukannya secara otomatis. Yang penting kamu paham konsep: model belajar dengan terus-menerus menyesuaikan bobot ke arah yang mengurangi loss.

💻 Kode Python

Implementasi dengan Keras

Keras menyembunyikan semua kerumitan matematika. Kita tinggal definisikan arsitektur, compile, dan fit.

Kasus: Prediksi Lulus/Tidak Lulus Mahasiswa

import numpy as np
import tensorflow as tf
from tensorflow import keras
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# ────────────────────────────────────────────────────────────
# STEP 1: Siapkan Data
# Fitur: nilai_uts, nilai_tugas, kehadiran_persen, jam_belajar
# ────────────────────────────────────────────────────────────
X = np.array([
    [0.8, 0.9, 0.85, 6],   # lulus
    [0.3, 0.4, 0.50, 2],   # tidak lulus
    [0.7, 0.6, 0.80, 5],   # lulus
    [0.2, 0.3, 0.40, 1],   # tidak lulus
    # ... tambah lebih banyak data
])
y = np.array([1, 0, 1, 0])  # 1=lulus, 0=tidak lulus

# Normalisasi fitur (penting! agar skala seragam)
scaler = StandardScaler()
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
X_train = scaler.fit_transform(X_train)
X_test  = scaler.transform(X_test)   # pakai .transform() bukan .fit_transform()

# ────────────────────────────────────────────────────────────
# STEP 2: Bangun Arsitektur Jaringan
# ────────────────────────────────────────────────────────────
model = keras.Sequential([
    # Hidden layer 1: 16 neuron, aktivasi ReLU
    keras.layers.Dense(16, activation='relu', input_shape=(4,)),

    # Hidden layer 2: 8 neuron, aktivasi ReLU
    keras.layers.Dense(8, activation='relu'),

    # Output layer: 1 neuron, aktivasi Sigmoid (output probabilitas)
    keras.layers.Dense(1, activation='sigmoid')
])

# Lihat ringkasan arsitektur
model.summary()

# ────────────────────────────────────────────────────────────
# STEP 3: Compile — tentukan cara belajar
# ────────────────────────────────────────────────────────────
model.compile(
    optimizer='adam',              # algoritma update bobot
    loss='binary_crossentropy',    # fungsi loss untuk klasifikasi biner
    metrics=['accuracy']           # metrik yang dipantau
)

# ────────────────────────────────────────────────────────────
# STEP 4: Training — model belajar dari data
# ────────────────────────────────────────────────────────────
history = model.fit(
    X_train, y_train,
    epochs=50,             # 50 kali lewati seluruh data
    batch_size=8,          # update bobot setiap 8 sampel
    validation_split=0.2, # 20% data train untuk validasi
    verbose=1
)

# ────────────────────────────────────────────────────────────
# STEP 5: Evaluasi & Prediksi
# ────────────────────────────────────────────────────────────
loss, acc = model.evaluate(X_test, y_test)
print(f"Akurasi Test: {acc:.2%}")

# Prediksi mahasiswa baru
mhs_baru = scaler.transform([[0.75, 0.80, 0.90, 5]])
prob_lulus = model.predict(mhs_baru)[0][0]
print(f"Probabilitas lulus: {prob_lulus:.1%}")
print("Prediksi:", "Lulus" if prob_lulus > 0.5 else "Tidak Lulus")

Visualisasi Hasil Training

import matplotlib.pyplot as plt

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))

# Plot accuracy
ax1.plot(history.history['accuracy'],    label='Train', color='#3b82f6')
ax1.plot(history.history['val_accuracy'], label='Validasi', color='#f59e0b')
ax1.set_title('Accuracy per Epoch')
ax1.set_xlabel('Epoch'); ax1.legend()

# Plot loss
ax2.plot(history.history['loss'],     label='Train', color='#3b82f6')
ax2.plot(history.history['val_loss'], label='Validasi', color='#f59e0b')
ax2.set_title('Loss per Epoch')
ax2.set_xlabel('Epoch'); ax2.legend()

plt.tight_layout()
plt.show()
