# M. Bahrul Subkhi — Personal Website

Personal academic and professional website for teaching, research, and software engineering.

## Main sections

- **About** — professional introduction
- **Teaching** — teaching areas, RPS, and learning resources
- **Research** — AI, machine learning, NLP, and computer vision interests
- **Engineering** — software engineering focus and technology toolkit
- **Publications** — Google Scholar search and public work links
- **Contact** — public collaboration channel

## Local preview

Open \`index.html\` in a browser, or run a static server from the repository root:

\`\`\`bash
python -m http.server 8000
\`\`\`

Then visit \`http://localhost:8000\`.

## Before publishing

1. Replace the temporary **BS** monogram with an approved professional portrait if desired.
2. Verify the exact Google Scholar profile URL and add LinkedIn / professional contact details.
3. Add only CV details, publications, and project case studies that are approved for public sharing.
4. Preview on mobile and desktop before pushing to GitHub Pages.
